Pick a file the way you would on a real exam portal. This page reads it in your browser only (nothing is uploaded) and prints exactly what the browser hands to a website: size, format, dimensions, JPEG type, DPI and a SHA-256. Compare the SHA-256 with the one on your computer to see whether any save or pick path changed the bytes.

    How to use this for QA (docs/TESTING.md section 5)
    1. Save a file from ScanFit, note its SHA-256 (shasum -a 256 file.jpg on a computer, or the app's file details).
    2. Open this page in Android Chrome, Samsung Internet and iOS Safari. Pick the file from each location the portal might use: Files / Downloads, the Photo Picker, and Photos.
    3. Bytes, dimensions and "JPEG type" must be unchanged. A different SHA-256 or size means that path re-encoded the file.

    Independent tool. Not affiliated with any exam body or government. KB here means 1024 bytes.
